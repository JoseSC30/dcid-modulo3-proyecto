# EntradasYa

Proyecto de servicios independientes en Node.js. Por ahora se contemplan
cinco servicios: auth, events, orders, payments y tickets, mas la aplicacion
web. Notifications y checkin quedan fuera del alcance actual.

- [Events](./events/README.md): catalogo y cupos, puerto 3000.
- [Auth](./auth/README.md): usuarios y autenticacion, puerto 3001.
- [Payments](./payments/README.md): pagos simulados, puerto 3002.

Orders, tickets y la web aun no estan implementados en este repositorio.
